# 🛠️Databricks bootcamp pipeline

This is a guided project I completed as a part of **Data with Baraa's Databricks 2 Day Live Bootcam Data**.

We ingested raw data and progressed it through Bronze, Silver, and Gold layers to produce clean, reliable, analytics-ready datasets, automating ingestion, transformations, and orchestration via pipelines and jobs.

# 🛠️ Tech Stack Used

* 🐍 **Languages:** Python, SQL
* 📈 **Data Processing:** Apache Spark, Pyspark
* ☁️ **Cloud Data Warehouse:** Databricks
* 📦 **Version Control:** Git/GitHub
